# E-Learning AI Hub

منصة تعليمية تفاعلية باللغة العربية تستفيد من نماذج **Google Gemini** لمساعدة المتعلمين على الفهم والمراجعة والتعلّم الصوتي، مع أدوات للتعاون المباشر بين الطلاب.

## نبذة عن المشروع

يوفّر المشروع مساحة واحدة للتعلّم المدعوم بالذكاء الاصطناعي، مع دعم العربية الفصحى وعدة لهجات عربية. يتكوّن التطبيق من واجهة React/TypeScript وخادم Express يمرّر طلبات الذكاء الاصطناعي ويعالج حدود الاستخدام اليومية.

## أبرز الميزات

- **المساعد التعليمي:** الإجابة عن الأسئلة وشرح المفاهيم والدروس بطريقة منظمة.
- **شرح الدروس:** إنشاء شرح تفصيلي للموضوعات التعليمية باللغة العربية.
- **البطاقات التعليمية:** استخراج المصطلحات المهمة من النص وتحويلها إلى أسئلة وأجوبة للمراجعة.
- **تحويل النص إلى صوت:** قراءة المحتوى بصوت اصطناعي مع اختيار صوت ولهجة مناسبة.
- **تحويل النص إلى بودكاست:** تحويل المادة التعليمية إلى حوار بين خبير ومتعلّم.
- **المحادثة الصوتية المباشرة:** تفاعل صوتي لحظي مع المساعد باستخدام Gemini Live API.
- **تحليل الملفات:** واجهة لمناقشة الملفات والمحتوى التعليمي مع المساعد.
- **التعلّم الجماعي:** إنشاء جلسة دراسة، مشاركة النتائج، الدردشة، وإجراء مكالمات صوتية بين المتعلمين عبر PeerJS.
- **تسجيل الدخول والاستخدام:** دعم Firebase Authentication، مع تتبّع الاستخدام اليومي عبر Firestore وإمكانية العمل بذاكرة مؤقتة عند عدم توفر Firestore.
- **واجهة عربية متحركة:** تصميم متجاوب مدعوم بـ Framer Motion وتجربة استخدام مناسبة للتعلّم.

## التقنيات المستخدمة

- **Frontend:** React 19، TypeScript، Vite، Tailwind CSS، Framer Motion
- **Backend:** Node.js، Express، Socket.IO
- **الذكاء الاصطناعي:** Google Gemini API عبر حزمة `@google/genai`
- **المصادقة وقاعدة البيانات:** Firebase Authentication وCloud Firestore
- **التواصل الصوتي المباشر:** PeerJS وWebRTC
- **إدارة الحزم:** Bun lockfile مع إمكانية استخدام npm أو Bun

## متطلبات التشغيل

- Node.js 18 أو أحدث
- مفتاح Google Gemini API
- إعداد Firebase للمصادقة وقاعدة البيانات عند الحاجة إلى الميزات المرتبطة بالحسابات

## التشغيل محليًا

1. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

2. أنشئ ملف `.env` اعتمادًا على `.env.example`، ثم أضف مفتاح Gemini:

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   ```

   يدعم الخادم أيضًا المتغيرات البديلة `VITE_GEMINI_API_KEY` و`VITE_GEMINI_API_KEY_1` و`GEMINI_API_KEY_1`.

3. شغّل بيئة التطوير:

   ```bash
   npm run dev
   ```

4. افتح التطبيق على العنوان الذي يعرضه الخادم، وعادةً يكون:

   ```text
   http://localhost:3000
   ```

## أوامر مفيدة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل الخادم وواجهة Vite في وضع التطوير |
| `npm run build` | بناء الواجهة وتجميع الخادم للإنتاج |
| `npm start` | تشغيل النسخة المبنية |
| `npm run lint` | فحص TypeScript دون إنشاء ملفات مخرجات |

## ملاحظات الاستخدام

- يفرض الخادم حدودًا يومية افتراضية قدرها **10 رسائل** و**300 ثانية من الصوت** لكل مستخدم.
- يتطلب استخدام الميكروفون منح المتصفح صلاحية الوصول إليه.
- لا تضع مفاتيح API أو بيانات Firebase السرية داخل المستودع. استخدم متغيرات البيئة، وتأكد من أن ملف `.env` غير متتبع عبر Git.
- عند عدم إعداد Firestore، يستخدم الخادم مخزنًا مؤقتًا داخل الذاكرة لتتبّع الاستخدام أثناء تشغيله.

